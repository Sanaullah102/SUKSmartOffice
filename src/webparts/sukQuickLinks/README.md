# SUK Quick Links

Quick Links supports six responsive display styles:

- **Tiles** keeps the original centered icon-and-label cards.
- **Pastel icon strip** places the icon beside the label on a soft-color card,
  like the horizontal layout in the design reference. Each card receives a
  different pastel background by default.
- **Service cards** uses outlined white cards with a left icon, bold link name,
  optional description, section heading, and optional "Lihat semua"
  link—matching the service directory reference design.
- **List rows** presents links as a full-width vertical list.
- **Rounded pills** lays compact links out as rounded, wrapping chips.
- **Compact tiles** uses smaller horizontal cards that automatically fit the
  available width.

Use the Display style, Icon position, Show link border, and responsive column
settings in the web-part properties to adjust the layout. Desktop, tablet, and
mobile column counts, card gap, padding, minimum height, icon size, text
alignment, colors, borders, shadows, and hover effects remain configurable.
For Service cards, add a description to a link using the in-page Add/Edit Link
form and configure the section-level see-all label and URL in the Section
properties. Individual links can override the global card/text colors. Existing
Quick Links items and settings continue to work with the original Tiles layout.

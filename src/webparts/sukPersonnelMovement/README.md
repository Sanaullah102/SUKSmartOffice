# SUK Personnel Movement

Displays staff placement, transfer, and retirement notices from a SharePoint
list. Select the list and map employee name, grade, position, placement,
effective date, category, and an optional item link. Category tabs are
configurable: set each tab label and its exact list value. If category tabs are
disabled or no category field is mapped, all loaded records are shown.

Five responsive layouts are available: **Classic table**, **Highlighted table**,
**Personnel cards**, **Date timeline**, and **Compact table**. Configure the
maximum number of records, heading, see-all link, empty-state message, and the
shared site-theme or custom appearance options.
